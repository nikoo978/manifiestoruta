Ruta Envios v2.5.3 - actualización limpia del repositorio

IMPORTANTE
- El ZIP contiene la RAÍZ del proyecto. No debe quedar dentro de otra carpeta manifiestoruta/ en GitHub.
- Copiar y reemplazar los archivos directamente en la raíz del clon, donde está el .git.
- La carpeta .git NO se borra.

Si en el repositorio existe una carpeta anidada llamada manifiestoruta, eliminarla antes del commit:
  rmdir /S /Q manifiestoruta

Después de copiar el contenido del ZIP, si querés refrescar el callejero oficial (requiere Internet y Node.js):
  ACTUALIZAR_CALLEJERO.cmd

Luego ejecutá:
  git status
  git add -A
  git commit -m "perf: optimize Android PWA and add loading status v2.5.3"
  git push origin main

Vercel debe compilar desde la raíz y mostrar v2.5.3 / Service Worker v24.
